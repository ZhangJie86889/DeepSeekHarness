DeepSeek Harness (dsh) — 便携版使用说明
==========================================

【给收到这个文件夹的人】
1. 把整个 DeepSeekHarness 文件夹解压到任意位置（D盘、E盘、桌面都行）。
2. 双击 start.bat 即可启动。
3. 启动后浏览器打开 http://127.0.0.1:3080
4. 在「设置 → 模型」里填入你的 DeepSeek API Key（或其他 OpenAI 兼容端点的 Key），保存后即可使用。

【前提条件】
- 需要 64 位 Windows（x64）。骁龙 ARM 笔记本无法运行（原生模块是 x64 编译）。
- 本文件夹已内置便携版 Node.js，无需自行安装 Node。
- 极少数老机器若缺少 Visual C++ 运行库，可能无法加载原生模块；一般 Windows 10/11 都自带。

【压缩 / 发送前请注意】
- node_modules 里有很多很深的目录路径。请用 7-Zip（或 Bandizip/WinRAR）打包，
  不要用 Windows 资源管理器自带的“发送到压缩(zipped)文件夹”，后者遇到超长路径会解压失败。
- 7-Zip 打包：右键文件夹 → 7-Zip → 添加到压缩包 → 压缩格式 zip 即可（默认支持长路径）。
- 若想发给别人一个“干净”的版本，可先清空 data 文件夹里的内容（只保留空 data 目录），
  那只会去掉你自己的设置和会话，不影响程序运行。

【命令行用法】
- start.bat            → 启动 Web UI（默认）
- start.bat --help    → 查看其他命令（如 headless 模式等）
